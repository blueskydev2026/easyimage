# גלריה זורמת

PWA מקומית לניהול וצפייה בתמונות:

- פתיחת תמונות מהמחשב.
- פתיחת תיקיית תמונות בדפדפנים שתומכים ב-File System Access API.
- דפדוף בחיצי המקלדת ובכפתורי ניווט.
- סרגל פעולות נסתר עם סיבוב, חיתוך, העתקה, שינוי שם, שינוי שם קבוצתי והדפסה.
- עבודה אופליין לאחר טעינה ראשונה.

להפעלה מקומית מומלץ להריץ שרת סטטי קטן בתיקייה:

```powershell
python -m http.server 8787
```

ואז לפתוח את `http://127.0.0.1:8787`.

## התקנה כ-PWA

פתחו את האפליקציה בכרום או Edge דרך הכתובת המקומית, ולחצו על כפתור `התקן` אם הוא מופיע.
אחרי ההתקנה אפשר לבדוק ב-Windows את `פתח באמצעות` עבור קבצי תמונה. בדפדפנים שתומכים בפתיחת קבצים ל-PWA, האפליקציה תקבל את הקובץ ותציג אותו ישירות.

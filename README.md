# EasyImage

EasyImage היא אפליקציית PWA בעברית לצפייה, עריכה, ארגון והדפסה של תמונות. היא עובדת מקומית בדפדפן, ללא שרת וללא העלאת תמונות לענן.

## פיתוח

```bash
npm install
npm run dev
```

## בדיקות ובנייה

```bash
npm run test
npm run build
```

## יכולות מרכזיות

- פתיחת תמונה אחת, מספר תמונות או תיקייה שלמה בדפדפני Chromium.
- גרירת תמונות לחלון.
- דפדוף, זום, התאמה למסך, תמונות ממוזערות, חיפוש ומיון טבעי.
- מצב צפייה ומצב עריכה במעבר מהיר.
- סיבוב, היפוך, בהירות, ניגודיות, רוויה, Undo/Redo ואיפוס.
- שמירה בשם, העתקה ללוח, שיתוף ומנהל הדפסה עם תצוגה מקדימה.
- PWA installable עם manifest, service worker ו-file handlers.

## פרסום ל-GitHub Pages

1. הרץ `npm run build`.
2. הריפו מוגדר לפרסום תחת `/easyimage/` באמצעות `vite.config.js`.
3. הפעל GitHub Pages במצב GitHub Actions.
4. דחיפה ל-`main` תריץ את workflow הפריסה ותפרסם את תיקיית `dist`.
5. ודא שהאתר נטען דרך HTTPS כדי לאפשר התקנת PWA מלאה.

## התקנת PWA

פתח את האתר ב-Chrome או Edge דרך HTTPS או localhost, לחץ על כפתור ההתקנה של הדפדפן או על כפתור "התקנה" באפליקציה, ואשר את ההתקנה.

## הגדרה כברירת מחדל ב-Windows

לאחר התקנת ה-PWA, פתח Windows Settings > Apps > Default apps, חפש EasyImage או את הדפדפן שבו הותקנה האפליקציה, ושייך סוגי קבצים כגון PNG, JPG, JPEG, WebP, GIF, BMP ו-AVIF. הדפדפן ומערכת ההפעלה חייבים לאשר את השיוך.

## מגבלות API

- פתיחת תיקייה וכתיבה לקבצים מקוריים תלויות ב-File System Access API וזמינות בעיקר ב-Chrome/Edge.
- דפדפנים אינם רשאים לשנות ברירת מחדל של Windows ללא אישור המשתמש.
- שיתוף והעתקת תמונה ללוח תלויים בתמיכת הדפדפן ובהרשאות.
- תמונות נשמרות בזיכרון רק בזמן העבודה ולא נשמרות מקומית ללא פעולה מפורשת.
